Sprint #50: Cron Alerting, SSO Token Proactive Refresh, & Admin Telemetry API

1. Cron Dead-Letter Logging & Alerting:
   - Wrapped `src/worker.js` `scheduled` handler in a `try/catch` block.
   - Built a dead-letter payload upon failure to record `{ error, timestamp, cron }`.
   - Logged failures to `TELEMETRY_KV` under the `alert:cron_failure:YYYY-MM-DD` key with a 14-day expiration TTL.

2. Proactive SSO Background Token Refresh:
   - Added `useEffect` in `src/hooks/useGameEngine.js` to continuously monitor `axim_sso_token` for expiration.
   - Triggers a POST to `/api/auth/refresh` 5 minutes prior to token expiration to automatically replace with new token in localStorage.
   - Added graceful handling (401/403) to prevent unexpected puzzle session loss.

3. Historical Admin Telemetry Summary API:
   - Built a `GET /api/admin/summary` route in `src/worker.js`.
   - Added requirement for `Authorization: Bearer <ADMIN_KEY>`.
   - Implemented `startDate` and `endDate` query parameters for fetching `DailyTelemetrySummaries` records gracefully.
